プライバシーポリシー

TOMOSHIBI WORKS（以下「私たち」）は、ゲーム「Vivid of Fade」（以下「本アプリ」）と、このウェブサイトでの情報の扱いを、次のとおり定めます。

1. 集める情報

本アプリは、名前・メールアドレス・位置情報・連絡先などの個人情報を集めません。アカウントの登録もありません。

ゲームの進み具合（セーブデータ）や設定は、お使いの端末の中だけに保存され、私たちに送られることはありません。

2. 通信について

本アプリは起動時に、最新の版とお知らせを確かめるため、外部のサービス Supabase に接続して情報を読み込みます。このとき送るのは読み込みの問い合わせだけで、セーブデータや個人を特定する情報は送りません。

通信のしくみ上、接続先のサービスには、お使いの端末の IP アドレスなどの接続の記録が残ることがあります。その扱いは Supabase のプライバシーポリシーに従います。

このウェブサイトは GitHub Pages で公開しており、文字の表示に Google Fonts を使っています。それぞれのサービスに、閲覧の記録が残ることがあります。

3. 広告・解析

本アプリとこのウェブサイトは、広告の表示や、利用状況の解析ツールを使っていません。

4. 変更

このポリシーを変えるときは、このページでお知らせします。
